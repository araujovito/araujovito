## English

I build data and AI projects on top of public data, and I treat every result as something a reader should be able to check. Methodology comes first and gets written down before the results, a finding that refutes the hypothesis is reported anyway, and verification scripts ship with the code.

## Português

Construo projetos de dados e IA sobre dados públicos, e todo resultado precisa poder ser conferido por quem lê. A metodologia vem antes e fica registrada antes dos resultados, um achado que contraria a hipótese aparece do mesmo jeito, e o script de verificação vai junto com o código.

Os projetos acima estão documentados em português. Destaques:

- **micropolis-agent:** por que agentes de linguagem jogam mal o SimCity original.
